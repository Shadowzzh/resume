## 2. 使用方法

不要按照技术教程从头完整学习。每个知识点按照下面的顺序复习：

1. 先说明它在项目中解决了什么问题。
2. 再解释核心原理和关键 API。
3. 准备一个真实问题或故障案例。
4. 完成一个与项目规模相符的小练习。
5. 用自己的语言回答相关面试问题。

掌握程度分为三档：

- `深入掌握`：能够设计方案、分析取舍、定位复杂问题。
- `熟练使用`：能够独立开发、联调和排查常见问题。
- `了解基础`：能够解释概念、阅读代码并完成简单修改。

对应当前简历：

- 前端、Vue、TypeScript、工程化：深入掌握。
- React、Next.js、Node.js、AI Agent：熟练使用，部分内容需要深入掌握。
- Go：熟练使用，重点覆盖跨平台工具开发。
- Java、Spring Boot：了解基础到熟练使用。
- Docker、Nginx、Linux：熟练使用。
- Kubernetes：了解基础，能够进行基础发布和排障。
