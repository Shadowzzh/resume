## 背景

安全业务包含多条产品线，需要一个统一的企业官网承载产品介绍、案例展示、咨询入口与资料下载，并支持栏目持续迭代。

## 我负责的部分

负责官网整体设计与前端开发，使用 Next.js + React + Tailwind CSS 搭建首页、产品线、案例、关于与联系等栏目，以及独立的下载中心页面；将页面结构、节区标题、卡片与按钮等重复逻辑沉淀为响应式共享组件，供各栏目复用。

咨询表单在客户端完成字段校验，提交到服务端路由后经邮件服务发送登记信息，接口侧同时处理参数校验与失败分支；下载中心提供访问校验与下载服务，按平台组织资料下载。

交付侧补充 standalone 构建输出、多阶段 Dockerfile 与容器编排配置。

## 结果

形成覆盖产品展示、案例、咨询与资料下载的企业官网；多栏目页面共享同一套响应式组件与页面结构，咨询与下载两条功能链路可端到端运行，并具备镜像化运行与部署配置。
